Analysing head direction cells over multiple epochs

The goal of this project is to apply fundamental pynapple operations to data recorded from head direction cells.

26.4 Compute head direction tuning curves

Now that we have all the components, see if you can figure out how to compute head direction tuning curves.
Good places to look for help are Chapter 20 and the Pynapple user guide on tuning curves.
You might want to consider how many bins to use and over which epochs to compute the tuning curves!

If all goes well, you should be able to select a couple units and make a plot that looks like this:

import matplotlib.pyplot as plt
selection = tuning_curves.sel(unit=[1,2,3])
plt.plot(selection.T)
plt.xlabel("head direction (rad)")
plt.ylabel("firing rate (Hz)");
